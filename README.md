# Beecrowd Java Solutions

This repository contains Java solutions for Beecrowd exercises. Each problem is implemented as a standalone `Main` class that reads from standard input and writes to standard output, following the platform's submission model.

## Project Structure

- `src/`: Java source files
- `src/exercises/beginner/pXXXX/Main.java`: individual Beecrowd solutions grouped by category and problem number
- `bin/`: compiled output generated by the Java project configuration
- `lib/`: optional external libraries

Current examples in the repository include:

- `exercises.beginner.p1175.Main`
- `exercises.beginner.p1176.Main`
- `exercises.beginner.p1178.Main`

## Compile

Compile all source files into `bin/` from the repository root:

```bash
javac -d bin $(find src -name "*.java")
```

## Run

Run an individual solution by using its fully qualified class name. For example:

```bash
java -cp bin exercises.beginner.p1178.Main
```

If you want to test another exercise, replace the class name with the corresponding package, such as `exercises.beginner.p1175.Main`.

## Notes

- Solutions are organized by Beecrowd category first, then by problem number.
- The workspace is configured to use `src/` as the source path and `bin/` as the output path.
- `src/App.java` is leftover template code and is not part of the exercise workflow.
